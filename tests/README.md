# 回归验收（tests/）

这些脚本是**真跑出来的**验收：启动真实的 exe、通过 CDP（Chrome DevTools Protocol）在渲染进程里执行断言、必要时读文件核对落盘结果。

**两条铁律：**

1. **绝不动你的真实数据。** 所有套件都把数据目录指到 `%TEMP%\np-*-profile`（通过 `NOTEPAD_PET_USERDATA` 环境变量），跑完只删那个临时目录。真实数据在 `%APPDATA%\notepad-pet-app`，测试不会写它。
2. **绝不抢鼠标。** 全部断言走 CDP（`Runtime.evaluate`），不合成鼠标事件、不调用 `SetCursorPos`/`mouse_event`。所以跑测试的时候你可以正常用电脑。

> 注意：套件开始和结束时都会**结束所有正在运行的桌宠实例**（保证连的是自己那个临时实例）。跑完不会自动把你平时用的那个拉起来，需要的话双击 项目根目录的 `桌宠.exe` 或跑 `启动桌宠.bat`。

## 一键跑

```powershell
cd C:\Users\lenovo\Desktop\桌宠
npm run test          # = tests\run-all.ps1：语法检查 + 综合验收 + 闹钟跨重启
```

也可以单独跑：

| 命令 | 覆盖内容 | 断言数 |
|---|---|---|
| `npm run check` | 四个源码文件 `node --check` 语法检查 | 4 |
| `npm run test:audit` | 综合验收（见下表） | 14 |
| `npm run test:alarm` | 闹钟跨重启与过期处理 | 5 |
| `npm run test:smoke` | 打包版冒烟（用打包好的便携版跑一遍关键项） | 4 |

> `test:smoke` 依赖 项目根目录的 `桌宠.exe` 存在；版本号变了要同步改脚本里的路径。

## 综合验收 `verify-audit.ps1` 覆盖什么

| # | 断言 | 为什么值得测 |
|---|---|---|
| 1 | 屏幕外的 `window.json` 会被夹回工作区 | 换显示器/拔副屏后桌宠会跑到屏幕外且拖不回来 |
| 2-3 | 菜单整块落在窗口内、形象按钮可见 | 曾经被顶到窗外 98px，按钮直接消失 |
| 4 | 闹钟带描述能落盘到 `alarm.json` | 闹钟跨重启的基础 |
| 5 | 时段任务到点提醒**不会**清掉已设的闹钟 | 曾经会被静默取消 |
| 6 | 提醒追讨中点桌宠仍然是提醒页 | 曾经会把正在追的提醒盖掉 |
| 7-8 | 慢点 10 下不换形态 / 连点 10 下换形态 | 与菜单文案一致 |
| 9 | 关掉再开「显示气泡」立即恢复 | 曾经要等最长 1 分钟 |
| 10 | 设置补丁只收已知键、非法音量回落 0 | 脏数据会污染配置 |
| 11-12 | 提前分钟数夹取后回写输入框、计数显示「· 未保存」 | 界面与模型不一致 |
| 13-14 | 广播不会冲掉未保存草稿 / 放弃改动能回滚 | 编辑静默丢失 |
| 15 | 重启后闹钟恢复（描述 + 剩余时间） | 端到端验证落盘与恢复 |

## 闹钟跨重启 `verify-alarm-restart.ps1` 覆盖什么

1. 设一个 4 分钟后的闹钟 → `alarm.json` 真的写进去了
2. 杀掉进程再启动 → 闹钟被恢复，剩余时间对得上
3. 设一个**已过期**的闹钟再重启 → 不补弹
4. 过期的 `alarm.json` 被清掉
5. 结束后无残留进程

## 目录

```
tests/
├─ run-all.ps1                 一键跑全部
├─ verify-audit.ps1            综合验收（14 项）
├─ verify-alarm-restart.ps1    闹钟跨重启（5 项）
├─ smoke-packaged.ps1          打包版冒烟（4 项）
├─ lib/cdp-eval.mjs            CDP 单次求值助手（支持 NP_PORT 换端口）
└─ payloads/*.js               被求值的表达式（用文件传，避免 PowerShell 吃掉引号）
```
